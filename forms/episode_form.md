# 一件真实事件的自我记录模板

> 尽量使用角色（同事/亲友/管理者），不要写真实姓名；可以跳过不愿记录的字段。

- 事件 ID（自定义）：
- 日期（只写日期即可）：
- 事件类型：沟通 / 工作 / 关系 / 决策 / 其他
- 当时希望实现什么（具体目标）：
- 可观察事实（当时谁做了什么，只记事实）：
- 约束（时间、权力、资源、风险、不可逆性）：
- 当时脑中的解释（这是我的想法，未必是事实）：
- 当时感受（0—10 强度可选）：
- 实际做了什么（不是我打算做什么）：
- 实际观察到的结果：
- 不知道或尚无法核实的地方：
- 解释 A（支持证据/反例）：
- 解释 B（支持证据/反例）：
- 哪个条件变化，会使当时的策略更合理或更不合理：
- 如果下次出现〔具体触发条件〕，那么我会〔一个明确动作〕：
- 下次复盘日期：
