# 证据、画像与可反驳性

## 1. 不做人格测验

情境回答不是测量“性格数值”。V0.1 没有心理测量学常模、效度研究或预测准确率，因此**不输出性格分数、百分位、稳定特质诊断或风险等级**。

## 2. 一个可复核的事件

事件字段分为：`observed_facts`（可描述的事实）、`thoughts`（主观想法）、`emotions`（主观感受）、`action_taken`（实际动作）、`outcome_observed`（已知结果）、`uncertainties`（未知）、`alternative_explanations`（竞争解释）。每份事件有 ID；允许缺失并明确表示。

`evidence_sources` 支持 `self_report`、`contemporaneous_note`、`observable_artifact`，它们表示材料类型，**不等于真实性认证**。不要求用户上传或分享证明材料。

## 3. 假设更新规则 v0.1

- `n=0`：没有真实事件；只展示用户表达的情境偏好。
- `n=1–2`：单例观察；不推断反复倾向。
- `n≥3`、至少 2 个不同日期、情境条件可比、至少一次明确寻找反例：可以展示**初步的条件性趋势**，标注 `n/符合次数/日期范围`。
- 条件差异很大（权力关系、后果严重性、是否可逆）时不得合并计数。
- 新反例必须与既有正例并列展示；用户可一键撤销假设。
- 绝不把 `n≥3` 说成“科学有效”或“人格已确定”。该阈值只是避免过早下结论的首版编辑规则。

## 4. 解释与反证

每个主张附 4 项：

1. 支持它的事件 ID 与条件。
2. 反例事件 ID 与条件（没有时写“暂无记录”，不能写“不存在”）。
3. 其他解释，如能力限制、环境限制、风险计算或错误记忆。
4. 一条可反驳预测，例如“下次在同等权力、低风险讨论中，你也会优先推迟表态”；下一次失败就修订假设。

## 5. 禁止的输出

“你的真实人格是 X”、“你本质上缺乏勇气”、“因为回答了 5 道题，你的成长潜力是 83%”、“某历史人物的选择证明你应该这样做”。

可接受输出：“在目前 3 次可比事件中，你有 2 次先搜集证据、再表达立场；这个模式不适用于尚无记录的紧急情境。”
