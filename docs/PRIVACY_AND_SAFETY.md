# 隐私与使用边界

本项目中的真实事件是个人内容，不是公共测试数据。

1. 首版静态页面默认**不向任何服务器发送**答案，不使用第三方脚本、分析 SDK、cookie 或 localStorage。用户主动下载 JSON 后自行保存。
2. **不要**把真实姓名、电话、公司名称、同事身份、精确住址、未公开商业信息、可定位的时间地点等写进 GitHub Issue/PR。
3. 示例全部为虚构，不代表真实参与者；代码测试仅使用虚构事件。
4. 任何情境分析只关注用户叙述中的选择、行为与约束；不凭空诊断心理疾病、鉴定危险性或推断第三方动机。
5. 用户可跳过题目、编辑、删除自己的本地记录。未来如上线账户系统，必须先提供明示同意、导出/删除机制、保留期限和数据处理说明。
6. 框架不是紧急援助工具；遇到暴力威胁、强迫控制、自伤危机等安全场景，停止常规“自我对抗训练”，先处理即时人身安全。
7. “与过去的自己对抗”仅作为对照行为策略的比喻，不采用羞辱、惩罚或自我攻击激励；变化失败不等同于人格失败。

## AI 输出约束

- 明确区分用户自述和系统推测。
- 每个解释给出替代解释和反驳途径。
- 不将敏感经历用于训练、展示、排行榜或增长运营，除非未来取得针对性同意。
- 用户不同意画像时，以用户纠正的事实为准，同时保留本地可追踪修订版本。
