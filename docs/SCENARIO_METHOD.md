# 情境题设计标准

## 每道题的最低结构

`情境（人物角色/目标/冲突）` + `约束（时间/权力/可逆性）` + `3 个合理选项` + `各选项收益与代价` + `变更条件` + `开放回答`。

**设计者必须能解释：为什么每个选项至少在一种具体条件下合理。** 无法解释的选项是陷阱题，应删除。

## 反例：不能这样提问

- “领导不合理，你敢不敢反抗？”（以勇敢为道德正确答案；没有权力与风险条件）
- “面对诱惑，你是不是自律？”（用抽象标签代替行为）
- “选 A 的人是讨好型人格。”（未验证的个体推断）

## 正例模板

> 你负责一个需明天下午提交的团队任务。同事提出的修改可能提高质量，但会使你无法按既定期限交付。上级尚不知情，你有权限主动沟通调整范围。
>
> A：先按时提交现有版本，同时记录待改项。
> B：主动与上级协商交期，争取补足质量。
> C：评估修改的关键部分，按风险排序局部调整。
>
> 你选哪项？什么新信息会使你改选？如果延期损失高于质量问题，选择会怎样变化？

三选项**不对应好坏分**。应为每项展示真实收益、真实代价、适用条件。

## 初期题库领域（12 题）

沟通分歧、工作取舍、功劳归属、边界设定、证据不充分、发现自身错误、短期诱惑、支持他人、资源不平等、隐私分寸、团队协作、挫败后的调整。

## 公开修订流程

- 新题以 PR 提交，附情境假设和每个选项的适用条件。
- 至少 2 名审阅者独立检查“诱导性、偏见、隐含标准答案、实际可选性”。
- 所有题目保留 `id`，文字变动记入 CHANGELOG；不回填、覆盖参与者历史选择。
- 题目不能自动推断稳定性格；若将来发展测量量表，需单独设计信效度研究。
