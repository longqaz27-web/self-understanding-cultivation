# v0.1 开放框架：情境 → 证据 → 假设 → 行动 → 复核

## 0. 目标与非目标

**目标**：增强用户对自己行为触发条件、选择与后果的观察能力，并让未来的行为调整可以由真实事件复核。

**非目标**：单次测验定义人格，预测他人真实动机，提供心理疾病诊断，以“伟人/名著”角色评判用户道德高低，或假称一套未经试验的算法能准确读取内心。

## 1. 数据优先级

| 信息 | 能够支持的结论 | 不能支持的结论 |
|---|---|---|
| 假设情境选择 | 当前表达的偏好/考虑 | 真实行为、稳定人格 |
| 真实事件自述 | 自述的行为和感受 | 未经验证的他人意图 |
| 结果或可检查证据 | 该事件的结果 | 行为与结果之间的确定因果 |
| 多次可比事件 | 限定情境的行为趋势假设 | 全场景终身标签 |
| 对照训练/前后比较 | 同一目标上的变化线索 | 未有对照就断言训练造成改变 |

## 2. 情境表征

一次情境必须包含：

- `goal`：当时至少一个具体目标；允许有冲突目标。
- `actors_roles`：角色关系，不含姓名。
- `time_pressure`：低/中/高；时间约束可以改变最佳策略。
- `power_balance`：对等/不对等/未知。
- `reversibility`：行为或结果是否容易撤回。
- `stakes`：潜在损失、机会成本、关系成本。
- `known` 与 `unknown`：用户真正知道什么、哪些只是猜测。

同一个“果断决定”在紧急场景可能是优势，在证据不足的不可逆决策中可能是风险。**框架评价策略与目标是否匹配，不对人格贴优劣标签**。

## 3. 用户旅程

### S1 低披露情境

从 12 张公开的情境卡任选 2—3 张；每题给出 3 个有合理动机的选项。用户可自行补充第四个选项，避免伪两难。首次不要求透露私事。

反馈只询问：选择理由、最担心的后果、改变选项的条件、与谁利益冲突。不做分数排名。

### S2 真实经历

用 `episode.schema.json` 记录事件。必须分别写 `observed_facts`、`interpretations`、`emotions`、`action_taken`、`outcome_observed`；未知可以显式写 `unknown`，不得编造空缺。

### S3 行为解释候选

先提出**至少两种**彼此竞争的解释。例：“回避对抗”可能来自冲突成本判断、信息不足或当时缺乏话语权。每个解释附支持证据、相反证据和待验证问题。

按 COM-B 分析能力 C、机会 O、动机 M：不能将结构性障碍都归咎于“个人意志力”。

### S4 限定情境的自我画像

默认输出 `证据不足，待观察`。仅当同类场景至少 3 次、跨至少 2 个日期、有行为事实且完成反例检查，才输出“初步情境性倾向”。这是产品内控门槛，不代表验证过的统计可靠性。

画像示例：“在对等合作关系、无立即安全风险、可延迟一天的争论中，你在已记录的 3 次事件里有 2 次先寻求信息，再表达立场。”

附条件、样本数、日期范围、反例、可能解释及下一次观察点。永远允许用户标记“不同意/信息有误/希望修改”。

### S5 人文镜鉴

每个历史或文学案例都按照同一字段拆解：角色目标、处境约束、行动、结果、记载来源、作者叙事立场、其他可行选择。经典提供对照视角，不提供标准人格。

### S6 可检验训练

最小单位为一条 `If–Then`：

- If：具体可识别的触发条件（谁/何时/发生什么）。
- Then：当场能完成的动作（如提 1 个澄清问题、明确告知边界）。
- 预期：希望改善的一个可观察指标。
- 风险：在何种条件下应停止或改用其他策略。
- 复核：下一次触发后的实际动作与结果。

### S7 一周复盘与版本更新

把事件列为：`触发且执行`、`触发但未执行`、`未触发`、`无法核实`。记录新的反例。必要时撤销旧画像，不默默改写历史事件。

## 4. 输出协议（所有实现必须遵守）

每条分析输出五段：

1. **观察**：仅陈述输入中有的行为或事件；引用事件 ID。
2. **候选解释**：至少两种，并标明尚未证实。
3. **情境条件**：说明结论适用于何种目标、关系、压力或约束。
4. **可反驳条件**：什么新观察会改变这次判断。
5. **小实验**：一条可执行、可复核的 If–Then。

**禁止**：仅凭选择题宣称人格类型、自动判断精神状态、猜测第三人真实动机、在记录缺失时补造事实、用文学隐喻代替真实证据、把用户任何行为天然贴成“缺点”。
