# 历史与文学镜鉴：看见策略，不是模仿伟人

把人性观察与现实行动相连时，每个案例都采用统一的 7 问：人物目标是什么？当时的客观限制是什么？叙述者掌握哪些证据？做出了什么选择？代价与受益者分别是谁？有哪些替代行动？对应用户现实场景时**哪些条件并不相同**？

## 首批阅读与讨论线索

| 作品 / 事件 | 可讨论的问题 | 不应直接推出的结论 |
|---|---|---|
| 《史记·廉颇蔺相如列传》：蔺相如的退让 | 冲突成本、公共目标与个人声誉 | 所有退让都是成熟 |
| 《史记·淮阴侯列传》：韩信受辱 | 当下反击与长期目标冲突 | 遇到侵害都应沉默 |
| 《论语》：三人行、择善而从 | 如何从不同人的行为中学习而不复制 | 古人所言必适用于现代处境 |
| 《傲慢与偏见》：伊丽莎白修正判断 | 证据更新、第一印象与误判 | 所有怀疑都来自偏见 |
| 《奥德赛》：面对塞壬之歌的预先约束 | 如何在冲动之前设计环境 | 自我约束总是正确，且无代价 |

> 上表是**阅读议题**，不是历史真实性或文学解释的独家结论。分析须回到具体章段和可信译本；本仓库不复制受版权保护的现代译文。

## 公开案例卡模板

- `source_work`：作品、篇章、书目与可核对出处。
- `source_reliability`：史料性质；小说必须注明“虚构人物/虚构情节”。
- `goals_constraints`：目标与约束。
- `behavior_outcome`：行为与叙述中的后果。
- `alternative_views`：至少 2 种解释及各自证据。
- `transfer_limits`：哪些历史/人物差异阻止直接迁移。
- `reflection_prompt`：指向现实中可观察的具体行为，而不是模仿古人身份。
